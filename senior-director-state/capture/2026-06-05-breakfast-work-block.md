## Free / Low-Cost AI and MCP Add-Ons To Consider

### Claude Custom Connectors / Remote MCP

Source: https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp

Use case for IIS:
- Connect Claude to controlled internal tools, proposal library, CRM/lead sheets, or tender tracker.
- Free users are documented as having one custom connector; paid plans get broader use.

Risk control:
- Only connect trusted servers.
- Disable write actions for research workflows.
- Use approval prompts for any external action.

### PnP CLI for Microsoft 365 MCP Server

Source: https://github.com/pnp/cli-microsoft365-mcp-server

Use case for IIS:
- Natural-language Microsoft 365 admin and audit workflows for SharePoint, Teams, Entra ID, Power Platform, Planner, and Outlook.
- Strong future service offering for M365 health checks and migration/support engagements.

Risk control:
- Start in a lab/demo tenant.
- Use read-only/audit prompts first.
- Never run destructive tenant actions without Ahmad approval.

### Softeria Microsoft 365 MCP Server

Source: https://github.com/softeria/ms-365-mcp-server

Use case for IIS:
- Microsoft Graph-based MCP server for Microsoft 365 and Office services.
- Useful because it advertises read-only mode and tool filtering, which fits a safer client-support model.

Risk control:
- Pilot only with least-privilege OAuth scopes.
- Keep write actions disabled until there is a tested runbook.

### Glama MCP Registry / Inspector

Source: https://glama.ai/

Use case for IIS:
- Search, inspect, and compare MCP servers before installing them.
- Helps avoid random MCP installs by checking tool schemas, licenses, and safety signals.

Risk control:
- Treat as discovery and test environment, not automatic trust.
- Install only tools that support business outcomes: M365, CRM, lead tracking, documents, browser/search, and help desk.
