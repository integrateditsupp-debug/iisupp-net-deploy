## Proposal Message

Hi,

I can help you build the WordPress website and driver recruiting/onboarding portal as a practical business system, not just a set of pages.

For this type of project, I would approach it in phases:

1. Website foundation
- Clean WordPress structure for your public pages.
- Recruiting pages for driver applicants.
- Mobile-first forms so applicants can complete the process from a phone.
- Clear calls to action for new drivers and dispatch/admin users.

2. Driver application and onboarding workflow
- Driver profile/application intake.
- Document upload flow for license, insurance, certifications, and other required files.
- Status tracking for submitted, missing documents, review, approved, and rejected.
- Admin dashboard to view applicants, filter by status, and see incomplete onboarding items.

3. Notifications and operations
- Email notifications for new applications and missing-document follow-up.
- Internal admin notes and handoff steps.
- Optional reminders for applicants who start but do not finish.
- Exportable applicant data if your team needs CSV/reporting.

4. Support and maintenance
- WordPress updates, plugin checks, backups, security review, and ongoing fixes.
- Post-launch improvements after your team starts using the portal.

My background is IT support, automation, Microsoft 365/cloud support, websites, and operational workflows, so I will build this with reliability and supportability in mind. The goal is to make the onboarding process easier for drivers and easier for your team to manage.

Suggested first step:
I would start with a short discovery call or written checklist so I can confirm:
- Required driver fields.
- Required documents.
- Current onboarding process.
- Who reviews applicants.
- Whether you need payments, e-signatures, background-check integration, or CRM/ATS integration.
- Hosting, domain, and existing WordPress access.

After that, I can provide a phased estimate and start with the core application flow first, then improve the admin workflow and automation.

Regards,
Ahmad Wasee
Integrated IT Support Inc.

## Discovery Questions

1. Do you already have WordPress hosting and a domain, or should setup be included?
2. Is there an existing website to rebuild, or is this a new build?
3. What driver types are you recruiting for?
4. What fields are mandatory in the application?
5. Which documents must drivers upload?
6. Do uploaded documents need expiration tracking?
7. Who reviews applicants, and how many admin users need access?
8. Do applicants need accounts, or should they submit without login?
9. Do you need e-signature, payment, background check, or dispatch/CRM integration?
10. Do you need SMS reminders, email reminders, or both?
