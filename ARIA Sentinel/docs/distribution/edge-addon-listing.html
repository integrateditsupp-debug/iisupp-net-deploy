ARIA Sentinel for Edge

Category: Productivity · Publisher: Integrated IT Support Inc. · Manifest V3

Short description

On-device browser support companion. ARIA Sentinel detects common browser faults (stale cache, stuck service workers, wrong zoom, login loops) and offers one-click, content-blind fixes — nothing leaves your machine.

Detailed description

  • Content-blind by design — page text, URLs, credentials and screenshots are never read or sent.
  • Per-site "leave me alone" toggle that syncs across your devices.
  • Auto-pauses when a tab is unfocused for 5 minutes.
  • Pairs with the ARIA Sentinel desktop agent (optional) over a strict localhost bridge.
  • Same code as the Chrome build; Edge-specific manifest only.

Permissions justification

  • storage — remembers your per-site preferences (no content).
  • scripting / activeTab — render the on-page helper and apply the fix you choose.
  • browsingData — clear cache for the current site only, on your click.
  • tabs — know which site the popup is acting on.

Privacy

Zero data-upload paths to iisupp.net. See the in-product Privacy verifier (10-second live network capture) for proof.
