## Known gaps the lab exposes (reported, not encoded as passes)

- **dnscache-stopped** — The DNS Client service cannot be restarted from a session; its recipe only refreshes the resolver, which fails while the service is down (a reboot or a person is needed).
- **dhcp-lease-stale** — The DNS refresh (dns-fail-v1) cannot renew a stale lease — renewing it needs `ipconfig /renew`, which needs administrator rights — so the item ends `not resolved` and goes to the IT contact; NET.DOWN gives the person the network guide meanwhile.
- **spooler-disabled** — No recipe may change a start type: the restart that Fix now or an approval runs fails honestly until an administrator re-enables the Print Spooler (the card says so).
- **winsock-corrupt** — The real fix (netsh winsock reset + reboot) exists only as an unbound Tier-0 catalog entry, so it can never run — correct for an L3 change; the DNS refresh now ends `not resolved` and the IT contact is told.
