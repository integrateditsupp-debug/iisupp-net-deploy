# Mode × level behaviour matrix — ARIA Sentinel fault lab

Generated 2026-10-14 by `tests/fault-lab-modes.test.mjs` from 139 scenarios run on the simulated Windows machine (`tests/lib/fault-lab.mjs`) against the real `src/main/main.mjs` (booted by `tests/lib/main-sandbox.mjs`). Every cell is what the lab OBSERVED; the test run rewrites this file — it is never edited by hand.

Setup: live fixes ON · a business device with one IT contact · the advise-first interval at 3 minutes · nobody answering anything · 40 minutes of (virtual) time · Sentinel on the standard user token (administrator rights only through a UAC prompt a person answers). **fresh** = nothing vetted yet (a new install); **trusted** = the fault's recipe has earned 12 vetted runs (Tier 1, the minimum the execution policy requires before anything runs unattended).

## Known gaps the lab exposes (reported, not encoded as passes)

- **time-drift** — No Windows watcher reports clock drift; the person has to say so, and the recipe is a guide (nothing to apply).
- **wlan-stopped** — The network watcher's NET.ADAPTER.DOWN for the same outage matches no recipe ("No local recipe matched").
- **dnscache-stopped** — The DNS Client service cannot be restarted from a session; its recipe only refreshes the resolver, which fails while the service is down (a reboot or a person is needed).
- **dhcp-lease-stale** — The watcher reports the DNS symptom (NET.DNS.FAIL → dns-fail-v1, a user-space refresh whose exit-code-only verify passes) while NET.DOWN matches no recipe — so the lease is never renewed and the internet stays down after a 'verified' fix.
- **spooler-disabled** — The service watcher (correctly) stays quiet for a Disabled service; only the person's report surfaces it, and no recipe may change a start type (re-enabling needs an administrator).
- **winsock-corrupt** — The real fix (netsh winsock reset + reboot) exists only as an unbound Tier-0 catalog entry, so it can never run — correct for an L3 change — but the DNS symptom is 'fixed and verified' while the internet stays down.
