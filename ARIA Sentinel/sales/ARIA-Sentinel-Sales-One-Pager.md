## How it works

1. **Watches** — runs resident on the machine, scanning for the issues that actually generate tickets (printer/queue, network/DNS, Office won't open, disk, drivers, Windows Update, BSOD, browser, performance).
2. **Diagnoses** — answers from a **280+ article knowledge base first, at $0**, instantly. Falls through to the cloud AI only when needed, then to an offline brain if there's no connection. The user always gets an answer.
3. **Fixes — under your control.** Three safety modes:
   - **Manual** — ARIA explains the fix; the user runs it.
   - **Confirmed** — ARIA proposes the fix as a one-click card; applies only on approval.
   - **Autonomous** — ARIA auto-resolves low-risk issues (self-repair); anything risky still asks first.
4. **Hands off from the web** — a user on iisupp.net/aria clicks **"Resolve it for me" → "Open with ARIA Sentinel"** and the desktop app takes the fix from there.
