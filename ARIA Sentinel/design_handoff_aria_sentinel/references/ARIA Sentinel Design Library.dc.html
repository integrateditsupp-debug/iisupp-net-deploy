Resident IT support that never sleeps. The source-of-truth component set for the ambient on-device agent — globe, fix cards, BSOD recovery, ServiceNow escalation, settings, and installer — rendered at production fidelity in gold-on-black.

BSOD & escalation · 05

BSOD takeover — the wow moment

On next boot after a crash, ARIA's "Solve it for me" option appears below the standard Microsoft recovery text (Tier A: BCD boot entry · Tier C: crash-on-resume fallback). It reads the minidump, matches the stop code locally, applies a known fix — or escalates.

BSOD & escalation · 06

ServiceNow escalation card

When local recipes can't resolve it, ARIA composes a ServiceNow incident — assignment group auto-selected from the signal, pre-filled with diagnostic context. The one intentional outbound path, and it goes to the customer's own ServiceNow instance, never to iisupp.net.

Auto-routing signal

BSOD & escalation · 09

Routing logic — assignment groups

ARIA classifies the unresolved signal and routes the incident to the correct ServiceNow assignment group. Six targets ship in v1, with Service Desk as the catch-all.

LOCAL FIX FAILS
confidence < 0.5, or 2 attempts exhausted
↓
ARIA CLASSIFIER
signal class → assignment group + priority
Desktop Support (DSS)
Hardware suspect · reimaging · physical device faults
Network Team
VPN infra · DNS server-side · connectivity outages
Security Team
Suspected malware · policy violations · quarantine
System Admins
AD · GPO · server-side configuration
Purchasing
Replacement parts · license renewals · procurement
Service Desk
Catch-all triage when class is ambiguous
Vision — collapse the L1–L3 ticket flood into one autonomous on-device agent. 70–80% of recurring user-end issues self-heal; only the genuine hands-on cases route to a human queue. The physical-work layer is the future robotics frontier.

First-run permission explainers

ARIA gets ahead of Windows' own warnings — explaining the SmartScreen notice and the UAC prompt before they appear, so the user isn't startled into cancelling.

⚠
About the SmartScreen notice
Windows may show "Windows protected your PC" because ARIA is newly published. Click More info → Run anyway. This is expected until code signing reputation builds — it's not a problem with the app.
Windows Defender SmartScreen prevented an unrecognized app from starting.
More info
◆
About the UAC prompt
You'll see "Do you want to allow this app to make changes?" once. ARIA needs elevation to run fixes and add the recovery boot entry. Click Yes — it won't ask again unless a fix requires it.

Privacy verifier

Privacy by engineering, not by promise. The verifier enumerates every outbound path in the binary. Recipes come down from iisupp.net; incidents go to your own ServiceNow. No user data path to iisupp.net exists — verifiable with any network monitor.
