ARIA API Reference · v0.1

Public Netlify-functions API. All endpoints are CORS-enabled, JSON-only. No auth required for marketing/sales surfaces; auth-gated endpoints are noted.

Contents: Embeddable widget Lead capture Live-agent handoff Data export Account delete Plan change M365 Graph Receipt email

Embeddable Widget

Drop ARIA on any third-party site as a floating chat bubble. Sub-3KB. CSP-safe.

<script src="https://iisupp.net/assets/aria-widget.js"
        data-color="#c5a059"
        data-position="bottom-right"
        data-title="Ask ARIA"
        async></script>

Data attributes (optional): data-color (default #c5a059), data-position (bottom-right|bottom-left), data-title, data-src (defaults to https://iisupp.net/aria).

Lead Capture

POST/.netlify/functions/aria-lead-capture

{ "name": "Jane Doe", "email": "jane@acme.com",
  "company": "Acme Inc.", "phone": "+14165551234",
  "message": "Looking for managed IT", "source": "/aria",
  "last_intent": "kb:m365" }

Emails Ahmad with a sales-ready lead card + confirmation back to the lead. Returns { ok: true, message }.

Live-Agent Warm Handoff

POST/.netlify/functions/aria-warm-handoff

{ "email": "user@co.com", "name": "Optional",
  "chat_summary": "USER: ... ARIA: ... USER: ...",
  "last_intent": "kb:windows", "urgency": "normal" }

Pages Ahmad with full chat context. Returns { ok: true, message: 'Ahmad is being paged now.' }.

Data Export (PIPEDA Principle 9)

POST/.netlify/functions/aria-data-export

{ "email": "user@co.com" }

Returns full data dump: Stripe customer + invoices, list of localStorage keys we set, Privacy Officer contact. Audit-logged.

Account Delete (GDPR right-to-erasure)

POST/.netlify/functions/aria-account-delete

{ "email": "user@co.com",
  "confirm": "DELETE-MY-DATA" }

Cancels active subscriptions, flags Stripe customer as deleted_by_request, emails customer + Ahmad. Requires exact confirm string.

Plan Change (Stripe Subscription)

POST/.netlify/functions/aria-plan-change

{ "email": "user@co.com",
  "new_tier": "pro" }

Swaps subscription to new tier with proration. new_tier: personal, pro, small_business, mid_size, enterprise. Returns updated sub + upcoming invoice preview.

M365 Graph (Read-Only Scaffold)

POST/.netlify/functions/aria-m365-graph

{ "action": "list-users",
  "params": { "top": 25 } }

Actions: health-check, list-users, get-user, check-license, list-groups, list-devices. Requires env vars M365_TENANT_ID, M365_CLIENT_ID, M365_CLIENT_SECRET (per-tenant). Use the platform readiness board to confirm the CEO/provider gates before enabling customer tenants.

Receipt + Session Email

POST/.netlify/functions/aria-receipt-email

{ "email": "user@co.com",
  "firstName": "Jane",
  "company": "Acme Inc.",
  "event": "session_start" }

Sends session receipt via Resend (primary) + Gmail SMTP (fallback). Used by /aria onboarding gate and trial-expiry hooks.

Quick Start (Curl)

curl -X POST https://iisupp.net/.netlify/functions/aria-lead-capture \
  -H 'Content-Type: application/json' \
  -d '{"name":"Demo","email":"demo@acme.com","message":"testing"}'
