ARIA Sentinel Admin Console

The public admin overview for ARIA Sentinel. The installed desktop console stays local and token-gated; this page explains what an authorized admin can manage without exposing source, customer data, or private app internals.

Licensing

Review plan status, trial state, revocation status, and upgrade paths. License secrets are masked and resolved server-side.

Fleet Status

View real-or-empty health, update, SLA, and privacy posture when customer endpoints are configured. Empty states never fabricate metrics.

Release Controls

Stage update manifests and evidence packs for review. Production publish remains an explicit authorized action.

Safety Gates

R11 private-folder lock, content-blind reporting, supervisor approval, countdown, and kill-switch controls remain enforced.

Admin access is not public. The live console requires customer-owned authority and the configured admin token. This page is informational only.
