Rule 14 — nothing fabricated in the UI
Never render vote counts, view counts, member/online counts, ratings, or testimonials until backed by real data. Below threshold, render the honest empty state (Trends, Experts, trust strip all ship empty-first). An honest empty beats a fake stat.
