## The model (transparent by design)
- **Hours saved = resolved fixes × 20 minutes / 60.** (20 min = default minutes-per-fix; adjustable to your real average.)
- **Dollars saved = hours saved × $75/hr.** ($75/hr = default blended IT rate; set it to your real rate.)
- Only **resolved fixes** count. A diagnosis is not a resolution. If ARIA has fixed nothing yet, this page shows "—", not a flattering zero.
- **Deflection % = resolved-without-escalation ÷ total ARIA conversations.** Shown only when both are real.
