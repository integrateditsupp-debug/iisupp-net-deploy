# IIS Loops

The IIS operating system. Read `docs/LOOPS_SPEC.md` first.

## What's here

```
loops/
├── README.md                  ← this file
├── CURRENT_GOAL.md            ← top-level goal (single source of truth)
├── registry.json              ← which loops exist + their status
├── cli/
│   ├── loops.mjs              ← /loops command implementation
│   └── goal.mjs               ← /goal command implementation
├── lib/                       ← shared helpers (currently empty)
└── *.yaml                     ← one file per loop, human-editable contract
```

## CLI

```bash
node loops/cli/loops.mjs list           # all loops + status
node loops/cli/loops.mjs show lead-radar
node loops/cli/loops.mjs graph          # spawn tree + writes docs/loops-graph.mmd
node loops/cli/loops.mjs budget         # $0/$100 cap check
node loops/cli/loops.mjs ledger         # last 50 events
node loops/cli/loops.mjs pause lead-radar
node loops/cli/loops.mjs resume lead-radar

node loops/cli/goal.mjs                 # print current top goal
node loops/cli/goal.mjs "new top goal"  # update, archives previous
```

Once `package.json` has `"loops"` and `"goal"` scripts wired:

```bash
npm run loops -- list
npm run goal
```

## What's NOT in this dir (intentionally)

- **Runners** — each loop's actual execution code lives at `netlify/functions/loop-runner-{id}.mjs`. Phase 1 placeholders; Phase 2 real runners as each loop is wired by Codex.
- **Ledger** — `docs/LOOPS_LEDGER.md`. The CLI appends here.
- **Graph** — `docs/loops-graph.mmd` regenerated by `loops graph`.

## Authoring a new loop

1. Copy an existing YAML as template.
2. Fill all 12 required fields per `docs/LOOPS_SPEC.md` §1.
3. `node loops/cli/loops.mjs add loops/your-id.yaml`  → schema-validated + registered.
4. Wire the runner under `netlify/functions/loop-runner-{id}.mjs` (Codex's lane).
5. Append a line to `docs/change-log.md`.

## Constraints every loop inherits

See `docs/COLLAB_BRIEF.md` §2 and `docs/LOOPS_SPEC.md` §7. The 9 locked rules. Loops that violate them are rejected by `loops add`.
