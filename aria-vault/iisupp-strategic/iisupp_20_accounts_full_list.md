# Tracking — single CSV to build

Create `/USA Outreach/named_accounts_20.csv` with these columns:

```
rank, company, hq_city, dm_name, dm_title, dm_email, dm_phone, dm_linkedin,
employee_count, vertical, observation, recent_trigger, angle, mutual_connection,
status, last_touch_date, last_touch_channel, next_action, next_action_date, notes
```

Status progression: `cold` → `engaged` → `discovery_booked` → `proposal_sent` → `negotiation` → `closed_won` / `closed_lost` / `graduated_dead`

Weekly Monday review. Move forward the active ones. Don't replace dead accounts until you've closed 3+ from the original 20.
