What this means for compliance answers

RFP / VPAT / SOC 2 questionnaire fields:
"Does the service support IPv6 end-to-end?" → Yes for inbound (CDN, web traffic, API endpoints). Outbound email path depends on upstream relay (Resend currently routes IPv4-preferred but accepts IPv6 source).

Verifying manually

dig AAAA iisupp.net +short
dig AAAA www.iisupp.net +short
curl -6 -I https://iisupp.net/

If a customer's network is IPv6-only

Netlify Edge serves dual-stack so no proxy is required. AROC + ARIA APIs all reachable on AAAA.
