AXIS LOCAL — Integrated IT Support Inc.

Lets Axis open things, build documents and code, and run approved tasks on your PC.

1. Install Node.js 18+ from nodejs.org.
2. (Recommended) Install Claude Code and sign in, so Axis can do real work on your PC.
3. Unzip this folder. Windows: double-click start-windows.bat. Mac: double-click start-mac.command.
4. In Axis, open "My PC", press "Pair this PC" and paste the key when asked.
5. Leave the window open. Axis sends tasks here; results show in Axis.

Safety: work stays in your AxisWorkspace folder. Commands never run until you approve them in Axis.
Remove a PC any time from Axis -> My PC -> Remove.
