Instruct an agent

Instructions are queued to the agent's inbox (/api/mesh-task-queue) and logged to the live feed. An agent that polls the queue (or the local bridge) picks it up on its next run. Conversational, reasoning replies cost an LLM call and stay off until you enable them through the governor.
