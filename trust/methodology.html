Test methodology

Every release runs tools/iis-tester-agent.mjs --all. Tests derived from our 22-vendor industry matrix.

How to reproduce

git clone https://github.com/integrateditsupp-debug/iisupp-net-deploy.git
cd iisupp-net-deploy
node tools/iis-tester-agent.mjs --all     # offline + report
node tools/iis-tester-agent.mjs --online  # live HTTPS probes

Where results live

Each run writes docs/iis-test-results-YYYY-MM-DD.md. The latest is linked from the Trust Center home. Historical runs are kept in the same directory so any buyer can see the trend.
