Three eval axes

  • Truthfulness — does the answer match a KB chunk?
  • Citation-grounding — is every factual claim traceable to a source?
  • Intent-match — did the routing pick the article the user actually needs?

How it works

An LLM-as-Judge layer (Gemini Flash) runs on every ARIA response. Below confidence threshold 8, the answer is routed to a human or refused — not fabricated. The grade per query is logged to the public observability endpoint at /.netlify/functions/aria-observability and aggregated nightly into a rolling 30-day rate.

Hallucination benchmarks

Industry standard: zero vendors publish a quantitative hallucination rate. Our rolling 30-day rate against curated probes (10 unknown-answer queries that should be refused, not answered) is published below as it's measured. We will also run TruthfulQA + HaluEval-QA quarterly and post the results.

Prompt injection / jailbreak

Industry standard: also zero. We test with a curated probe set of 10 jailbreak prompts every release. Pass threshold: 100% blocked. Any leak of a secret value is a P0 incident published in the security log.

Comparison

The two closest public eval frameworks are Aisera CLASSic (5 narrative dimensions) and ServiceNow Now Assist's 9-metric framework. Both describe the framework; neither publishes a number. Atlassian Rovo uses gpt-4o-mini as a judge but doesn't publish judge agreement. Intercom Fin claims 99.9% accuracy on $1M-guaranteed plans — no eval methodology published. We're not better than the rest because we ship more rules; we're better because we tell you the score.
