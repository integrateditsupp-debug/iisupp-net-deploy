ARIA Sentinel

Public Desktop + Web Contract

ARIA Sentinel is the local Windows desktop agent for guarded IT support. The web surface can explain, triage, and hand off; the desktop app performs local actions only through visible approval gates.

Public endpoints

  • aria-recipes returns the public recipe registry and global kill-switch metadata.
  • aria-stop-codes returns stop-code guidance for BSOD and crash triage.
  • aria-kb-bundle returns the public KB bundle used by web and desktop fallback paths.
  • aria-recipe-feedback accepts content-blind recipe feedback and measured outcomes.

Safety model

Local fixes remain gated by supervisor review, a cancelable countdown, the Ctrl+Alt+K kill-switch, R11 private-folder blocking, and content-blind audit logging. The web page never sends a system command to the desktop app.

Integrations

ServiceNow, Microsoft Graph, CRM, RSA, and Microsoft 365 document connectors report honest connected, not_configured, or error states. Credentials are customer-owned and are not embedded in public pages.
